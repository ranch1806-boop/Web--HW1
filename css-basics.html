Раздел 1. Назначение CSS

CSS используется для изменения внешнего вида HTML-элементов: цвета, размера, отступов и расположения.

Название CSS раскрывается как Cascading Style Sheets, или «каскадные таблицы стилей». HTML задаёт структуру документа, а CSS описывает его представление. Благодаря этому один и тот же документ можно оформить по-разному, сохранив заголовки, абзацы, списки и ссылки на своих местах. CSS применяется прежде всего при оформлении веб-страниц.

Разделение содержания и оформления удобно при работе с несколькими страницами. Например, у учебного сайта есть главная страница, раздел с формами и две страницы паспорта. Общие правила можно записать один раз и подключить там, где они нужны. Если изменить правило, оно будет действовать на все элементы, к которым подходит его селектор.

Селектор указывает, какие элементы документа нужно оформить. Селектор тега подходит ко всем элементам выбранного типа: правило для p может изменить вид всех абзацев. Селектор класса начинается с точки и позволяет объединить несколько элементов по назначению. Селектор идентификатора начинается со знака решётки и используется для конкретного элемента с соответствующим атрибутом id.

После селектора в фигурных скобках записывают объявления. Каждое объявление состоит из свойства и значения, разделённых двоеточием. Свойство color задаёт цвет текста, font-size — размер шрифта, background-color — цвет фона. Точка с запятой отделяет одно объявление от следующего. Переносы строк помогают читать код, но сами по себе не меняют оформление.

Каскад позволяет применять к одному элементу несколько правил. Браузер сопоставляет их происхождение, важность и специфичность, а при равных условиях учитывает порядок записи. Поэтому появление нового правила не обязательно отменяет все предыдущие: каждое свойство выбирается отдельно. Один абзац может получить цвет из одного правила, размер шрифта из другого, а отступ из третьего.

Некоторые свойства наследуются от родительского элемента. Если задать цвет текста для блока, вложенный абзац обычно получит тот же цвет, пока для него не установлено другое значение. Наследование сокращает количество повторений. Однако размеры, рамки и отступы не следует считать автоматически наследуемыми: для нужного результата их задают подходящими правилами.

Для понимания расположения элементов важна блочная модель. У элемента есть содержимое, внутренний отступ, граница и внешний отступ. Содержимое занимает основную область. Внутренний отступ отделяет его от рамки, а внешний — от соседних элементов. Если картинка расположена слишком близко к тексту, нужно сначала определить, какой именно отступ требуется изменить.

В учебном макете паспорта CSS нужен для размещения текста поверх фоновой картинки. Контейнер задаёт область документа, а отдельные надписи получают координаты относительно него. При этом фамилия и имя остаются HTML-текстом: JavaScript может прочитать их или заменить после нажатия кнопки. CSS отвечает за положение надписей, а не за сами паспортные данные.

Единицы измерения выбирают в зависимости от задачи. Пиксели подходят для фиксированных размеров, проценты задают величины относительно другой области, а единицы, связанные со шрифтом, удобны для текста. В этом проекте координаты полей паспорта задаются в процентах, чтобы надписи меняли положение вместе с размером шаблона при сужении окна.

Раздел 2. Способы подключения

  1. Внешний файл CSS.
  2. Элемент style внутри страницы.
  3. Атрибут style у отдельного элемента.

Внешнюю таблицу стилей подключают элементом link внутри head. В атрибуте href указывают путь к файлу, а значение rel="stylesheet" сообщает браузеру назначение подключения. Файл может находиться в той же папке, что и HTML-документ, или в отдельном каталоге. Важно, чтобы относительный путь был записан правильно.

На страницах паспорта этого сайта подключён файл css/style.css. Он содержит правила для фонового шаблона, фотографии и текстовых полей. Информационные страницы используют стандартное оформление браузера. Таким образом, общий CSS не требуется подключать ко всем документам: его используют только там, где необходимо специально разместить элементы.

Внешний файл удобен, когда одинаковые правила нужны нескольким страницам. Если поправить положение фамилии в одном CSS-файле, изменение будет применено к обеим страницам паспорта. Это помогает сохранить одинаковую геометрию. При отдельных копиях правил в каждом HTML-файле пришлось бы делать одну и ту же правку несколько раз.

Второй способ — поместить правила в элемент style внутри HTML-документа. В этом случае таблица стилей находится непосредственно на странице. Такой подход удобен для небольшого отдельного примера: можно увидеть разметку и оформление в одном файле. Если же страниц много, общие правила обычно проще поддерживать во внешнем файле.

Третий способ — указать атрибут style у элемента. В нём записывают объявления без селектора и фигурных скобок. Например, style="text-align: center;" задаёт выравнивание текста у выбранного элемента. Этот способ помогает быстро оформить один фрагмент, но при повторении на десятках элементов делает разметку более длинной и трудной для редактирования.

Подключение CSS и выбор селектора решают разные задачи. Подключение делает правила доступными странице. Селектор определяет элементы, на которые эти правила распространяются. Даже правильно подключённый файл не изменит нужный абзац, если класс в HTML написан иначе, чем класс в CSS. Поэтому при проверке сначала смотрят путь к файлу, затем имя класса.

Пути внутри CSS вычисляются относительно самого CSS-файла. Например, правило фона паспорта содержит url("../assets/images/passport-template.png"). Две точки означают переход из папки css на уровень выше. Затем браузер переходит в папку ресурсов и находит изображение. Это отличается от пути картинки в HTML, который считается относительно HTML-документа.

Изменения оформления удобно проверять в инструментах разработчика. После выбора элемента браузер показывает применённые правила и их источники. Если свойство перечёркнуто, оно уступило другому правилу. Если фон не появился, можно проверить наличие файла и правильность пути. Такая проверка помогает найти причину, не меняя всю страницу наугад.

После сохранения CSS нужно обновить страницу. Иногда браузер продолжает использовать ранее загруженную копию файла. В таком случае помогает обновление через Ctrl+F5. Если исправление касается нескольких страниц, следует открыть каждую из них: одна страница может подключать правильный файл, а другая — содержать устаревший путь.
