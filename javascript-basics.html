Раздел 1. DOM

DOM представляет HTML-документ как дерево объектов. Элемент можно найти по идентификатору:

document.getElementById('name').innerText

JavaScript — язык программирования, который широко используется на веб-страницах. В браузере он позволяет реагировать на действия посетителя и изменять содержимое документа. HTML описывает элементы страницы, а JavaScript обращается к ним через предоставляемые браузером интерфейсы. Одним из таких интерфейсов является DOM, или объектная модель документа.

DOM представляет документ в виде дерева узлов. У дерева есть корневые элементы и вложенные части: заголовки, абзацы, ссылки, изображения и текст. Такое представление позволяет программе находить отдельные фрагменты, читать их содержимое и менять его. Исходная разметка и текущее дерево документа могут различаться, если скрипт уже добавил или изменил элементы.

Идентификатор элемента задаётся атрибутом id. Метод document.getElementById ищет элемент по этому идентификатору. В кавычках указывают имя идентификатора, а не видимый текст. Например, в поле имени паспорта идентификатор равен name, хотя посетитель видит слово «Михаил». Именно поэтому команда поиска использует слово name.

После поиска программа получает объект элемента. У объекта есть свойства и методы. Свойство innerText позволяет прочитать отображаемый текст, а присваивание нового значения изменяет его. Для поля ввода обычно используют value, поскольку введённое пользователем значение находится в этом свойстве. Выбор свойства зависит от типа элемента.

Если элемента с указанным идентификатором нет, метод возвращает null. Попытка обратиться к тексту такого результата вызывает ошибку. При её появлении нужно проверить написание идентификатора и убедиться, что открыта нужная страница. Например, команду для паспортного поля нельзя выполнять на главной странице, где такого поля нет.

В учебной странице фамилия, имя и год рождения находятся в отдельных элементах span. Фоновая картинка паспорта не содержит этих значений. Поэтому команда в консоли действительно читает данные из HTML, а не распознаёт надпись на изображении. Такой способ позволяет наглядно показать разницу между картинкой и текстовым содержимым страницы.

Для поиска также существуют методы, возвращающие группы элементов. Например, getElementsByTagName выбирает элементы с заданным именем тега. К найденному элементу можно обратиться по индексу, начиная с нуля. Этот способ используется в примере преподавателя, но зависит от порядка абзацев: добавление нового абзаца перед паспортом изменит номера следующих элементов.

Идентификаторы удобны, когда программе нужен конкретный элемент с определённым назначением. Они не должны повторяться в одном документе. Классы, наоборот, могут использоваться у нескольких элементов. В паспорте класс задаёт расположение надписи через CSS, а идентификатор помогает JavaScript найти нужное поле. Один HTML-элемент может иметь оба атрибута одновременно.

Консоль браузера позволяет выполнить выражение и сразу увидеть результат. На странице считывания паспорта достаточно получить три значения. Скриншот с паспортом и результатами служит подтверждением выполнения задания. Ошибочная команда в консоли не меняет файл проекта, но для итогового снимка удобнее очистить старые сообщения и выполнить правильные команды заново.

Раздел 2. События

JavaScript может выполнять функцию после нажатия на кнопку.

  1. Найти кнопку.
  2. Добавить обработчик события click.
  3. Изменить нужный текст в DOM.

Событие сообщает программе, что произошло действие. Например, посетитель нажал кнопку, изменил поле ввода или закончил загружать страницу. Обработчик события — функция, которую браузер вызывает в ответ. Это позволяет подготовить программу заранее, а выполнять нужное действие только в подходящий момент, когда пользователь взаимодействует со страницей.

Для кнопки удобно использовать событие click. Сначала скрипт находит кнопку в DOM, затем связывает её с функцией через addEventListener. После этого каждый щелчок вызывает обработчик. Внутри функции можно прочитать поля, выполнить вычисления или заменить текст. Само подключение обработчика не означает, что функция уже выполнилась.

На странице изменения паспорта обработчик переключает все внесённые текстовые данные между русским и английским вариантами. Цифры года рождения сохраняются, а подпись «г.» меняется на year. При повторном нажатии возвращается русский текст. Картинка шаблона остаётся на месте, а страница не перезагружается.

Порядок выполнения имеет значение. Если искать кнопку до того, как браузер создал её элемент, поиск не даст нужного результата. Скрипт можно подключить после разметки или дождаться события DOMContentLoaded. На наших страницах обработчики подключаются после подготовки документа, чтобы элементы паспорта и формы уже были доступны программе.

Событие input возникает при изменении значения поля. Оно полезно, когда старый результат больше не соответствует новым данным. В алгоритмической задаче после изменения суммы признак выполненного расчёта сбрасывается. Поэтому перед отправкой изменённой суммы нужно снова нажать «Рассчитать». Это связывает результат с актуальными исходными данными.

Нажатие кнопки расчёта не обязано отправлять форму. Тип button позволяет выполнить обработчик и оставить посетителя на странице. Кнопка отправки выполняет другую задачу: передаёт поля формы по указанному адресу. Такое разделение есть в примере преподавателя, где сначала проверяют исходные данные, а потом отдельно отправляют результат на сервер.

В обработчике вычислений значения из формы сначала читают как данные. При необходимости их преобразуют в числа и проверяют допустимость. Для задачи о размене отрицательная сумма не подходит, дробная сумма не является целым числом рублей, а нечётную сумму нельзя получить из чётных номиналов. Результат проверки записывается в видимое поле.

События помогают отделить действия пользователя от описания алгоритма. Функция расчёта может принимать сумму и возвращать результат независимо от кнопки. Обработчик связывает эту функцию с полем ввода и выводом на странице. Такое разделение упрощает проверку: один и тот же алгоритм можно использовать в браузере и проверять на нескольких исходных значениях.

Для проверки обработчика нужно выполнить конкретное действие и сравнить состояние страницы до и после. На паспорте меняется текст фамилии и имени. В задаче появляется количество купюр и монет. Если ничего не произошло, стоит проверить, подключён ли JavaScript-файл, правильно ли указан идентификатор кнопки и нет ли ошибки в консоли браузера.
