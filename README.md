Проект состоит из обычных HTML, CSS и JavaScript-файлов без фреймворков и внешних библиотек. Начальная страница — `index.html`. Оформление намеренно минимальное и повторяет подход учебных примеров: стандартный шрифт браузера, обычные списки ссылок, закладки и простые HTML-формы.

## Что обязательно заменить перед сдачей

1. В `passport-dom.html` и `passport-change.html` заменить `ГГГГ` на настоящий год рождения.
2. В `forms.html` заменить `УКАЖИТЕ ГРУППУ`, демонстрационный телефон и `student@example.com` на нужные данные. Не использовать настоящий пароль в поле демонстрационного кода.
3. На странице `passport-dom.html` выполнить в консоли браузера:

```js
const surname = document.getElementById('surname').textContent.trim();
const name = document.getElementById('name').textContent.trim();
const birthYear = document.getElementById('birth-year').textContent.trim();
console.log({ surname, name, birthYear });
```

Затем сделать снимок окна браузера вместе с DevTools, сохранить его в `assets/images/` и заменить блок `<div class="screenshot-placeholder">` в `passport-dom.html` элементом `<img>` со ссылкой на настоящий файл.

## Локальный запуск

Сайт не требует сборки. Его можно открыть напрямую через `index.html` или запустить простой статический сервер из папки проекта, например расширением Live Server в редакторе.

## Публикация на GitHub Pages

1. Создать репозиторий на GitHub и загрузить содержимое этой папки в ветку `main`.
2. В репозитории открыть **Settings → Pages**.
3. В разделе **Build and deployment** выбрать **Deploy from a branch**, ветку `main`, каталог `/ (root)` и сохранить.
4. После публикации открыть выданный адрес и повторно проверить навигацию, картинки, формы, DOM-страницы и задачу № 1006.

## Удалённый сервер форм

По примеру преподавателя формы отправляются методом GET на `https://www.bing.com/search`. На странице задачи вместе отправляются формулировка, исходная сумма и рассчитанный результат.
